# visuospatials.com

A visual hub for design and artwork, within music, or any other medium.
By Gregor Egan & Hunter Bowersmith. Los Angeles & Santa Cruz.

**[visuospatials.com](https://visuospatials.com)**

## The lab

Five rooms of browser instruments. Everything runs on your own machine — nothing
you drop in is uploaded anywhere — and every room exports at print resolution.

| | |
|---|---|
| **Halftone** | Any image to dot halftone, ordered or diffusion dither, ascii, scanline, crosshatch |
| **Moiré** | Interference fields from two overlaid grids, steered by the pointer |
| **Type** | A kinetic type specimen that copies its own CSS |
| **Poster** | A seeded generative poster; every composition has an address you can return to |
| **Studio/About** | What this is, and how to bring something to it |

## Running it

Static HTML. No build step, no dependencies, no analytics, no fonts fetched from
anyone. Clone it and serve the folder:

```
python3 -m http.server 8000
```

Deployed from `main` with GitHub Pages.
